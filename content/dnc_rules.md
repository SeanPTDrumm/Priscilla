# Dingoes & Crowns

The table game uses **3d6** and the shared flow:

**ANTE → CALL & COVER → THROW → PAY**

The named result categories are **Crown, Pair, Road, and Dingoes**.

> **Prototype note:** the authoritative category-resolution/ranking text was not present in the Player Portal seed available to this build, so the portal deliberately does **not** invent it. The dice roller, public calls/stakes, pots, side bets, and Climb tracker are functional; the DM can add the exact ranking text later without changing the rest of the page.

## Shared table etiquette
Called bets and stakes are public at the table. The portal's shared state is visible to all logged-in players. Private cheating mechanics are intentionally deferred.
